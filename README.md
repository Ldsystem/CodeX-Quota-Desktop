# Codex Quota Desktop

Scaffold for a React + Electron desktop app that will eventually replace / wrap the `codex-quota` CLI.

This repository currently contains **project scaffolding only**. Product behavior, UX, and CLI integration details are intentionally deferred.

## Stack

- Electron + electron-vite
- React + TypeScript
- pnpm

## Develop

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```
